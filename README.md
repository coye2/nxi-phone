# NX Infinity phone (PWA)

Built files only.

Open https://coye2.github.io/nxi-phone/ in Safari or Chrome on your phone, wait until it says the app is available offline, then Add to Home Screen. In Setup import your own prod.keys and firmware, then add your games. Nothing you import leaves your device.

No games, keys or firmware are included.
